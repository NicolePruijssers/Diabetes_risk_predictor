# Diabetes_risk_predictor
This project is built on a synthetic dataset. Synthetic datasets are meant to mimic patterns in real-life data, but are only an approximation. It does not represent real patients. This limits the reliability of this model when applied to real data.
mobeenfatimah/diabetes-risk-prediction-dataset-50k-patients 

The aim of this project is to create a model that can independently estimate the risk an individual has to develop type II diabetes. Two columns indicated the risk factor, one in categories and one in numerical score. The latter was deemed to be more accurate and the former was removed from the dataset.
First, several data cleaning and reduction techniques were applied. >0.01% of rows were dropped due to missing age. Due to this small number and the apparent lack of reliable data collection, it was deemed acceptable to drop these rows. For numeric columns were filled with the mean of the given column. ~0.01% of rows had one empty text column. This concerned the columns medication_adherence, which may simply not be relevant, and physical activity level, which can be hard to determine in certain cases. These empty values were filled with 'Unknown'. 
For data reduction, height and weight were dropped after it was verified that the given BMI's were correctly calculated. Furthermore, all columns that represent or are directly linked to diagnostic factors were dropped to avoid data leakage. In response to the results of the early development models and the permuation_importance scores, more columns were dropped later to reduce data noise. The columns in question are subject to change during development and are recorded in the comments of the script. An additional column was added to count how many reported diseases each individual had.
The pd.get_dummies() function was used to turn the partially textual datasets into a shape suited for data modelling. A randomforestclassier(n_estimators=200, random_state=42, n_jobs=-1) was applied and trained to predict a scalar risk score from 0-100. Afterwards, a permuation importance calculation was applied. After removing columns that were shown to cause noise in the model, were removed, the following performance scores were given; 
MAE (average points between predicted and real value): 8.955
RMSE (difference between MAE and RMSE indicates presence of error outliers): 10.723
R² (percentage of variation in target values that can be explained by the model): 53.5%
These scores indicate a modest accuracy of the model. It is yet to be determined if this is caused by a sub-optimal feature selection and machine learning model or if the dataset is simply too variable. 
More interesting results were found in the permutation importance. While each separate disease reported had little impact in the predicted score, the number of diseases had the largest impact of all features. Further important features were indicated need for doctor consultation, age, and BMI. It is worth considering the possiblity that diabeted risk is most strongly tied to overall health, rather than individual factors.
